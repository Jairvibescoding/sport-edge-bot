# SPORT EDGE BOT 🏆

Bot de Telegram para apuestas deportivas con monitoreo automático.

## Características

- ✅ Monitoreo automático de apuestas
- ✅ Notificaciones en Telegram
- ✅ Comandos interactivos
- ✅ Funciona 24/7 en la nube

## Comandos

- `/start` - Bienvenida
- `/status` - Ver apuestas
- `/bankroll` - Ver dinero
- `/stats` - Ver estadísticas
- `/picks` - Ver picks del día
- `/win [número]` - Marcar ganada
- `/loss [número]` - Marcar perdida

## Despliegue en Render

1. Sube este código a GitHub
2. Conecta Render con tu repositorio
3. Configura la variable de entorno `TELEGRAM_TOKEN`
4. ¡Listo! Bot 24/7

## Tecnologías

- Python 3.11
- Flask
- Telegram Bot API
